# Otagai mobile

The Expo app contains the neighbourhood feed, marketplace, requests, and Ask assistant. Routes are under [`src/app`](src/app/) and use Expo Router. Shared components are in [`src/components`](src/components/), the API client is in [`src/lib`](src/lib/), and design tokens are in [`src/theme`](src/theme/).

Follow the [local development guide](../docs/development.md) to set up the API, configure Supabase, and run the app and checks. The [push setup guide](../docs/request-push-setup.md) covers device builds and credentials.
